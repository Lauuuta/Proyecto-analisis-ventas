# Proyecto de analisis de ventas de pequeño negocio.

# Integrante del proyecto
- Lautaro Delgadillo Solari

El objetivo del proyecto es crear y analizar un archivo CSV sobre ventas de un pequeño supermercado y generar resultados de indicadores basicos a partir de los datos obtenidos

# El proyecto se divide en 3 partes:

Datos: Creación de un archivo CSV sobre ventas de un pequeño supermercado.
Scripts: Implementación del codigo en Python para generar el analisis.
Resultados: Generación de un archivo CSV en base a los resultados generados en el analisis.

# El dataset contiene informacion de ventas sobre los productos:
- Nombre del producto
- Cantidad de unidades
- Precio por unidad
