# Proyecto de analisis de ventas de pequeño negocio.
El objetivo del proyecto es crear y analizar un archivo CSV sobre ventas y generar resultados de indicadores basicos a partir de los datos obtenidos

El proyecto se divide en 3 partes:

Datos: Creación de un archivo CSV sobre ventas de un pequeño supermercado.
Scripts: Implementación del codigo en Python para generar el analisis.
Resultados: Generación de un archivo CSV en base a los resultados generados en el analisis.
